# AP Dev Solutions, LLC

Software for Maine assessing practices.

## Commitment Desk

**Commitment Desk** is an in-development workspace for the annual assessing cycle: deadlines,
evidence, documents, current-use work, and the office-side workflow that leads to commitment.

The first module is **Commitment Desk Inbox**, a capture inbox that receives field inspection and
permit records, validates them, and routes them through an office review queue. It is currently in
private development and will be released under Apache 2.0 when it is forkable and working.

## Projects

- **Commitment Desk Inbox** — private development; intended Apache 2.0 release.
- **Commitment Desk Platform** — private office platform.

## Status

Early-stage. The inbox is being built privately; the office platform remains private.
