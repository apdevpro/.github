# AP Dev Solutions, LLC

Software for Maine assessing practices.

## Commitment Desk

**Commitment Desk** is an in-development workspace for the annual assessing cycle: deadlines,
evidence, documents, current-use work, and the office-side workflow that leads to commitment.

The first public module is **Commitment Desk Inbox**, an open-source capture inbox that receives
field inspection and permit records, validates them, and routes them through an office review
queue.

## Open source

- [Commitment Desk Inbox](https://github.com/apdevpro/commitment-desk-inbox) — Apache 2.0
  capture inbox, API, and review UI.

## Status

Early-stage. The inbox is being scaffolded in public; the office platform remains private.
